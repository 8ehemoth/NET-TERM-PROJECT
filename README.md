# 네트워크프로그래밍및실습

강원대학교 네트워크프로그래밍및실습 수업에서 진행한 TCP 기반 GUI 클라이언트·서버 프로젝트와 학습 기록을 정리한 저장소입니다.

C++과 Windows 소켓 API를 활용해 사용자 ID 등록과 채팅 메시지 전송 기능을 구현했습니다. 메시지 형식을 정의하고, 서버와 클라이언트가 해당 형식에 맞춰 데이터를 주고받는 과정을 학습했습니다.

현재 저장소에는 개발 과정의 코드가 포함되어 있으며, 전체 텀 프로젝트의 최종 제출본과 실행 환경은 추가로 정리할 예정입니다.

## 학습 내용

| 주제 | 주요 내용 |
| --- | --- |
| TCP 소켓 | 소켓 생성, 서버 연결 대기 및 클라이언트 접속 |
| 메시지 형식 | 등록·채팅 메시지 타입과 길이 정보를 활용한 데이터 처리 |
| GUI 연동 | 대화상자에서 사용자 ID·메시지 입력 및 내용 표시 |
| 스레드 | 클라이언트 연결별 서버 처리 스레드 구성 |
| 동기화 | 이벤트 객체와 임계영역을 활용한 처리 순서 및 공유 접근 관리 |

현재 공개 코드에서 확인할 수 있는 기능은 다음과 같습니다.

- 클라이언트의 TCP 서버 접속
- 사용자 ID 등록 메시지 전송 및 서버 표시
- 채팅 메시지 전송 및 서버 표시
- 서버에서 송신 클라이언트로 응답 전송
- 클라이언트 연결별 서버 스레드 생성

현재 공개된 클라이언트에는 서버 응답을 수신·표시하는 코드가 포함되어 있지 않으며, 서버도 전체 클라이언트에 메시지를 전달하는 브로드캐스트 구조는 아닙니다.

## 저장소 구성

| 파일 | 주요 역할 |
| --- | --- |
| `Client.cpp` | GUI 입력, TCP 연결, ID 등록 및 채팅 메시지 전송 |
| `Server.cpp` | 연결 수락, 클라이언트별 스레드 생성, 메시지 수신·표시 및 응답 전송 |
| `README.md` | 프로젝트 소개와 학습 내용 |

수업 예제를 바탕으로 기능을 확장한 코드가 포함되어 있습니다. 코드에서 참조하는 공통 헤더·GUI 리소스·Visual Studio 프로젝트 파일은 추가 정리가 필요합니다.

기존 수업 필기는 프로젝트 소개와 구분해 별도 문서로 정리할 예정입니다.

## 사용 언어 및 환경

- 언어: C++
- 운영체제: Windows
- 개발 도구: Visual Studio
- 주요 API: Winsock2, Windows API
- 통신 방식: TCP
- 기본 접속 설정: `127.0.0.1:9000`

현재 공개된 파일만으로는 빌드에 필요한 구성이 모두 갖춰져 있지 않습니다. 최종 제출본 확인 후 필요한 파일과 실행 절차를 보완할 예정입니다.

## 학습한 점

소켓 연결뿐 아니라 서버와 클라이언트가 동일한 메시지 형식을 사용해야 데이터를 올바르게 해석할 수 있다는 점을 배웠습니다.

메시지 타입과 길이 정보를 이용해 데이터를 구분하고, GUI 입력과 네트워크 송신을 스레드로 연결하는 과정을 실습했습니다. 이벤트 객체와 임계영역을 사용하며 여러 실행 흐름 사이의 동기화도 학습했습니다.

또한 TCP에서는 송신 호출 단위와 수신 데이터의 경계가 항상 일치하지 않으므로, 수신 길이와 버퍼 범위를 확인하는 처리가 필요하다는 점을 익혔습니다. 현재 코드의 부분 송수신 처리와 연결 종료 시 자원 정리는 보완할 항목으로 남겨두었습니다.
