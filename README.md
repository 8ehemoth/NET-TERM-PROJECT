# TCP 기반 GUI 클라이언트·서버

네트워크프로그래밍및실습 수업에서 진행한 텀 프로젝트입니다.

C++과 Windows 소켓 API, 대화상자 기반 GUI를 활용해 사용자 ID 등록과 채팅 메시지 전송 기능을 구현했습니다. 메시지 형식을 정의하고, 서버와 클라이언트가 해당 형식에 맞춰 데이터를 주고받는 과정을 학습했습니다.

이 저장소에는 개발 과정의 서버·클라이언트 코드가 포함되어 있습니다. 전체 텀 프로젝트의 최종 제출본과 실행 환경은 추가로 정리할 예정입니다.

## 개발 환경

- 언어: C++
- 운영체제: Windows
- 개발 도구: Visual Studio
- 주요 API: Winsock2, Windows API
- 통신 방식: TCP
- 기본 접속 설정: `127.0.0.1:9000`

## 현재 공개 코드의 구현 내용

### TCP 서버·클라이언트 연결

서버는 소켓 생성, 주소 바인딩, 연결 대기 후 클라이언트의 접속을 수락합니다. 클라이언트는 지정된 IP와 포트로 서버에 연결합니다.

### 사용자 ID 등록

사용자가 입력한 ID를 등록 메시지로 전송합니다. 서버는 메시지 타입을 확인하고 ID 길이와 문자열을 수신해 화면에 표시합니다.

### 채팅 메시지 전송

등록 메시지와 채팅 메시지를 서로 다른 타입으로 구분했습니다.

채팅 메시지는 헤더와 ID·메시지 문자열을 나누어 전송하며, 서버는 길이 정보를 이용해 각 데이터를 수신합니다. 수신한 내용은 서버 화면에 표시하고 송신 클라이언트에 다시 전송합니다.

현재 공개된 클라이언트 코드에는 서버 응답을 수신·표시하는 기능이 포함되어 있지 않습니다.

### 스레드 및 동기화

- 서버는 접속한 클라이언트마다 처리 스레드를 생성합니다.
- 클라이언트는 이벤트 객체를 이용해 GUI 입력과 송신 스레드 사이의 처리 순서를 조정합니다.
- 서버의 출력 함수에는 임계영역을 사용했습니다.

## 코드 구성

| 파일 | 주요 역할 |
| --- | --- |
| `Client.cpp` | GUI 입력, TCP 연결, ID 등록 및 채팅 메시지 전송 |
| `Server.cpp` | 클라이언트 연결 수락, 처리 스레드 생성, 메시지 수신·표시 및 응답 전송 |

코드에서 참조하는 공통 헤더와 GUI 리소스, Visual Studio 프로젝트 파일은 추가 정리가 필요합니다.

## 메시지 처리 흐름

### ID 등록

1. 클라이언트 GUI에서 사용자 ID를 설정합니다.
2. 최초 전송 시 등록 메시지 헤더와 ID 문자열을 보냅니다.
3. 서버는 메시지 타입과 ID 길이를 확인해 등록 정보를 수신합니다.
4. 서버 화면에 수신한 ID를 표시합니다.

### 채팅 메시지

1. 사용자가 GUI에 메시지를 입력합니다.
2. 클라이언트는 메시지 타입, ID 길이, 메시지 길이를 담은 헤더를 전송합니다.
3. ID와 메시지 문자열을 순서대로 전송합니다.
4. 서버는 헤더의 길이 정보를 이용해 데이터를 수신합니다.
5. 수신 내용을 화면에 표시하고 송신 클라이언트에 응답합니다.

현재 코드는 여러 클라이언트의 접속을 스레드로 처리하지만, 전체 클라이언트에 메시지를 전달하는 브로드캐스트 구조는 아닙니다.
